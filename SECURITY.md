# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Instead, contact the repository owner privately through GitHub. Include:

- A clear description of the issue.
- Steps to reproduce it.
- The browser and version used.
- A proof of concept only when it is safe to share.

Reports involving script injection, unsafe links, unexpected network access, or malicious Markdown rendering are especially welcome.
